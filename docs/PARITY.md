# 与 tvbox-silicon 的对照

移植基线：`030330f67eda8edf8f29e6611c1cb9ed03734f85`。Android 使用原生视图重新实现，无法复用 SwiftUI、Apple 播放器或系统 Liquid Glass。当前目标是逐步对齐 tvOS 版本；以下表格记录实际范围，不能把“入口存在”当成全功能一致。

2026-11-10 范围调整：以轻量为目标，保留常规电影、电视剧、直播和音乐；移除漫画页面、阅读器、Venera 脚本和专用宿主实现，不接入红果等官方内置短剧源。漫画不再属于待补齐项。网盘/媒体服务器功能也按用户要求移除，包括 AList/OpenList、Emby/Jellyfin 和 WebDAV 接入；订阅、历史、收藏和离线下载继续保留。

android.4-tv：内置默认 FTY 订阅快照与 ItaloDance Radio；未适配源按策略隐藏，现有 JAR 宿主保留作后续适配使用，未完成验证的 JAR 源不直接展示。当前测试结果与源清单以 [TV 版验证记录](TV_RELEASE_REPORT.md) 和 [源适配记录](SOURCE_SUPPORT.md) 为准。

## 验证边界

ARM32 的 QuickJS SO 已使用 Android NDK 真正编译；打包脚本检查 ELF 为 32 位 ARM，并验证 APK 签名。应用运行与视频解码测试使用 Android 12 / API 31 ARM64 TV 模拟器，另构建 ARM64 JNI 供测试使用。没有接入用户的 ARM32 小米电视，因此不能宣称已在该电视上验证。

最低 Android 5 的声明不代表所有插件都能使用：尤其依赖 `CompletableFuture` 的新式 JAR SDK 需要 Android 7。安装后可先用 JSON 或 JS 订阅确认网络、遥控器和硬件解码，再验证用户实际使用的 JAR 源。

本地文件导入支持包含完整远程地址的配置。SAF 单文件授权不能自动取得相邻脚本/JAR 文件；含相对本地附件的订阅需要改为可访问的 HTTP 目录。局域网手机输入服务只在主页面前台运行。
