# 1.8.15-android.5-tv

- 新增应用内检查更新、后台下载、进度展示及校验后调用系统安装器；启动时每天自动检查，可在设置关闭。
- 更新校验安装包大小、SHA-256、包名、版本、ARM32 原生库及签名，拒绝不同签名的覆盖安装。
- 直播支持 EXTINF 请求头、同频道多线路归并、失败/长时间缓冲时自动切换备用线路；频道列表与线路列表分开。
- 视频快进/后退步长可设置，按语言与名称保留音轨/字幕偏好。
- 下一集提前解析并复用结果，减少切集等待；可关闭，不预下载整集或创建额外解码器。
- 扩展音乐源尝试从 QQ/网易云补同一录音的歌词，不匹配的版本不混用。
- 修正重复版本推送导致 Release 失败；没有固定签名时仅构建验证包，不发布不可连续覆盖安装的版本。

首次安装本版本后，后续更新无需再用 U 盘或电脑传安装包，但仍需在电视系统安装界面确认。首次可能需要允许映匣安装未知应用。
